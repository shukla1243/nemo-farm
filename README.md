# NEMO FRNS FARM

Island life sim for Rare Friends, built with [FriendSDK 1.0](https://github.com/rarefriends/friendsdk).

This is version 0.1.0 of game id `nemo-farm`: a coming-soon screen. Your Friend waits on the island dock while the
full game is built. It declares no actions, items or server rules, so it needs no contracts or deployment record.

```sh
npm ci
npx friendsdk dev     # http://localhost:4173 with fixture Friends
npx friendsdk check
npx friendsdk build   # .friendsdk/build
```

Publishing steps for the Rare Friends team are in [HANDOFF.md](HANDOFF.md). The full game will replace this build as
version 1.0.0 of the same id.
